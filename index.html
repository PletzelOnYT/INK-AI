03 / Your model, your repository

NO THIRD-PARTY INFERENCE

The drawing interface downloads its own trained weights from this GitHub repository only. Recognition runs in a dedicated browser worker. No canvas data is sent to GitHub. The Python/PyTorch trainer builds the weights; this HTML performs inference without installing PyTorch.

How the AI works and what it cannot do

The convolutional neural network uses EMNIST samples from real people and may include HASYv2 examples. The workflow also augments handwriting and creates synthetic punctuation. Similar glyphs such as I / l / 1 / | are intrinsically ambiguous; sentence context can help, but results are not guaranteed. Handwritten connected cursive can defeat character segmentation. Corrections remain in this browser until exported; automatic GitHub writes require a secure authenticated backend, which is intentionally not embedded in public HTML.
